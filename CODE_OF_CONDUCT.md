# QGIS Cloud Community Guidelines

Welcome to the QGIS Cloud Community! To keep this forum useful for everyone, please follow these simple guidelines.

## Be respectful

Treat other community members with respect. Harassment, insults and abusive behavior are not tolerated.

## Stay on topic

Keep discussions related to QGIS Cloud and its features.

## Search before posting

Check the [QGIS Cloud documentation](https://docs.qgiscloud.com/en/) and existing discussions before asking a question.

## Provide useful information

When asking for help, describe your problem clearly and include relevant details, error messages or screenshots.

## Protect sensitive information

Never share passwords, API keys, access tokens or other confidential information.

## Community support

This is a community-driven forum where users help each other. Participation is voluntary, and responses from the QGIS Cloud team are not guaranteed.

## Official support

For official technical support, please visit [QGIS Cloud Support](https://support.qgiscloud.com/).
